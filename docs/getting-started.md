# Getting started

Career Agent is the sole supported product. Follow [the Career guide](career.md)
for installation, startup, profile review, JD analysis and resume generation.
`waku` and `waku career` launch the local workspace at `http://localhost:7777/#overview`.

## Configure a provider

Copy `.env.example` to a local `.env` and set `WAKU_PROVIDER` plus the selected
provider's scoped key. You can also configure the provider through Career Settings.
Settings keep keys on the server and report masked readiness to the browser.
Provider defaults, endpoint overrides and model catalogs follow
[the provider registry](providers-registry.md).

Batch B1 removes the obsolete chat, Memory, integration and teaching walkthroughs.
Git history preserves them. Existing runtime data and configuration stay intact.
